# 구조 분석 개발 문서

최신 구조 분석 코드는 이제 **MusicAnalysisHarness/apps/score-workbench**에서 관리한다. MusicStructureAnalyzer와 MusicSearch의 기존 폴더·Git 이력은 보존했으나 이번 통합 이후의 개발 기준은 통합 저장소다.

문서를 물리적으로 재배치해 상대 링크와 과거 사례 ID를 깨뜨리지 않도록 원 웹 문서 폴더를 유지한다. 이 파일은 다음 정본으로 연결하는 단일 진입점이다.

- [개발 문서 지도](../../apps/score-workbench/docs/README.md)
- [현재 구현 상태](../../apps/score-workbench/docs/SYSTEM_STATUS.md)
- [구조·웹 개발 로그](../../apps/score-workbench/docs/development-log.md)
- [Claude 2층 Phrase 통합 기록](../../apps/score-workbench/docs/phrase-layer-integration.md)
- [Claude Motif 가족 통합 기록](../../apps/score-workbench/docs/motif-family-integration.md)
- [사례 지식베이스](../../apps/score-workbench/docs/evaluation-case-knowledge-base.md)
- [통합 출처와 검증](../REPOSITORY_CONSOLIDATION.md)

Phrase 2층과 Motif 가족 비교는 기존 계약대로 opt-in 실험 레이어다. 이번 통합에서 기존 Phrase/Motif/화성/피드백 ID를 교체하거나 실험 분석을 기본 분석으로 승격하지 않는다.
