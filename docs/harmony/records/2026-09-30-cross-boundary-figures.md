# 화음 경계를 넘는 조건부 비화성음

기록 ID: HARM-DEV-20260930-01. 연구용 구현·회귀 검사·고정 실제 표본·전체 악보 화면. 운영 승격/음악적 정답률 검증 아님.

## 문제와 목표

[직전 유지·분할 비교](2026-09-29-common-candidate-segment-contrast.md)는 분할한 각 구간 내부에서만 경과/보조 형태를 설명했다. 같은 화음도 범위를 잘라 놓으면 경계를 넘는3음 설명이 사라졌다. 이번에는 기존 설명을 덮어쓰지 않고 **분할 양쪽 후보와 동일 성부 경로의 전후 문맥**을 연결한다.

기존 `harmony_residual_audit`의 선행음/실제 지속 계류 geometry와 `counterpoint_evidence`의 철자 기반 경과/보조 geometry를 검토했다. 기존 strict 단선율/기본 후보 계약을 변경하지 않고, 공통 후보·전체 성부 연결 가정에 맞는 별도 모듈로 연결했다. 새로운 교재 단원을 독해하거나 외부 모델을 학습시킨 작업은 아니다.

## 일반 규칙

### 경계를 넘는 경과/보조 형태

- 같은 전체 성부 연결 assignment의 실제 연속3음을 사용한다. 쉼을 뛰어넘거나 다성음에서 가까운 음을 임의 연결하지 않는다.
- 세 sound의 전체 길이가 관찰 문맥에 포함되어야 한다. 철자/옥타브/MIDI가 일관돼야 한다.
- 첫 음과 끝 음은 각각 실제로 걸치는 모든 화음 구간에서 구성음이어야 한다.
- 중간음은 실제로 걸치는 모든 화음 구간에서 비구성음이어야 한다. 경계 한쪽에서 구성음이 되는 음을 전체 길이의 경과음으로 처리하지 않는다.
- 기존 spelling-aware 경과/반음계 경과/보조 geometry를 따른다. 화음이 같거나 달라도 이 조건에 맞으면 조건부 형태를 보존한다.
- NCT 확정, 강박/약박 적합성, 제거 가능한 음, 화음 변경 정답을 뜻하지 않는다.

### 선행음 후보

- **재타격형:** 앞 음 release와 같은 철자·같은 옥타브의 다음 attack이 가정 경계에서 정확히 맞닿아야 한다. 앞에서는 비구성음, 뒤에서는 구성음이고 같은 assignment에서 연결돼야 한다. 이명동음이나 옥타브 차이를 동일 재타격으로 보지 않는다.
- **지속형:** 하나의 실제 sounding event가 가정 경계를 넘으며 앞 비구성음→뒤 구성음이어야 한다. NCT 설명은 경계 **앞부분의 음가**에만 적용한다.
- 음가·강세·양식 조건은 아직 검증하지 않았으므로 가능성 설명이다. 지속형은 무연결 assignment에도 하나의 실제 sound로 존재할 수 있다.

### 준비된 계류음 후보

- 하나의 실제 sound가 앞 화음의 구성음으로 시작해 경계를 넘어 뒤 화음의 비구성음으로 지속되어야 한다.
- 해당 sound의 release에 바로 연결된 뒤 음이 같은 assignment에서 하행2도(철자상 한 도수,1/2반음)로 뒤 화음 구성음에 도착해야 한다.
- NCT 설명은 경계 **뒤부터 실제 release까지**만 적용한다. 준비 단계의 구성음 음가를 NCT로 바꾸지 않는다.
- 다시 타격한 동일음은 타이/계류로 간주하지 않는다. 상행 해결, 지연·장식된 해결, 성부 전이, preparation이 문맥 밖인 경우는 이번 규칙에서 주장하지 않는다.
- 수직 불협화와 박절·양식 조건 미확인: 확정 suspension이 아니라 `prepared_suspension_candidate`다.

## 계약과 기존 결과 보존

- `harmony_boundary_figures.observe`는 경계별 geometry에 호환되는 앞/뒤 후보 색인과 supporting assignment refs를 저장한다. 앞×뒤×assignment 조합 전체를 정답처럼 열거/투표하지 않는다.
- 양쪽 후보의 grace/철자/기타 보류를 유지한다. 기존95개의 철자 대조 보류를 우회하지 않는다.
- `compare`는 선택한 조합에서 적용 가능한 패턴을 계산하고, **미설명 비구성음의 해당 시간 셀**에만 조건부 설명을 추가한다. 구성음·철자 미정 음가와 총 note-time은 변하지 않는다.
- 동일 음을 여러 패턴이 설명해도 음가를 중복 가산하지 않는다. 원음표/타이/지속시간은 수정하지 않는다.
- 기존184 sample JSON은 실행 전후 hash 불변. 새 결과에서 추가 필드를 제거하면 기존 sample 전체와 일치함을 검사했다. 기존120개 preview 비교도 그대로 재계산 일치한다.
- 기존 `preview_comparison`은 보존하고 `boundary_context_preview`를 추가한다. Core/원주석/기존 화음 선택기/운영5173/구조 분석은 미변경이다.

## 확인 가능한 사례

K281 III `reviewm_555ff701230fc0b8ee66`, sample15, 기존 B♭ major→E♭ major 분할 가정과 동일한 성부 연결:

- B♭5–A5–G5의 첫/끝 음이 각 구간에서 구성음, A5는 뒤 구간에서 비구성음이다.
- 가정 경계는 global quarter10, A5 적용 범위는 `[10,21/2)`다.
- 기존 분할: 구성음11/2, 조건부 NCT0, 미설명 비구성음1/2, 전체6quarter.
- 경계 문맥 추가: 구성음11/2, 조건부 NCT1/2, 미설명0, 전체6quarter.
- 구성음 비율이나 선택된 화음은 바꾸지 않았다. 유지 쪽 E♭ major 가정도 그대로 남는다. 무연결 대안을 고르면 경과음 설명은 양쪽 모두 성립하지 않는다.

화면의 ‘유지 / 분할(이전) / 분할+문맥’은 같은 음가의 전후 비교다. 구간 표시와 주황 분할 가정 점선, 유지와 새 분할 해석 사이의 차이는 보라색으로 표시한다. A5가 양쪽에서 같은 조건부 경과음 상태가 되면 보라색 차이 표시는 없어지고, 오른쪽에 근거 음형이 남는다.

## 결정과 다음 단계

채택한 것은 **경계 문맥을 잃지 않는 조건부 설명과 정확한 음가 보존 계약**이다. 판정기 승격은 보류한다.

다음은 화성 교체의 실제 긍정 근거와 NCT의 필수 조건을 더 분리하는 것이다. 박절·베이스와의 수직 음정·준비/해결 강도·화성 리듬을 연결하기 전에, 이 고정 표본에서 생긴 후보의 반례를 점검하고 계류/지속 선행음의 실제 양성 사례를 별도 고정한다. 해당 사례의 선정 방식과 원주석 의존 여부를 기록한다. 조건부 설명이 많아졌다는 사실만으로 화음 경계·종지·Phrase를 변경하지 않는다.
