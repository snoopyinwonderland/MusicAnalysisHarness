# 동일 문맥의 화음 유지·분할 비교

기록 ID: HARM-DEV-20260930-07. 버전: `shared-harmonic-context-0.1.0`.

## 문제와 결정

이전 비교는 유지 가정의 local NCT 설명과 분할 가정의 경계 문맥 설명을 결합했다. 경계 때문에 한쪽만 앞뒤 음을 잃거나 추가 근거를 받으면 설명량을 공정하게 비교할 수 없다. 이번에는 **같은 음표 범위·성부 연결·음형 규칙**에서 양쪽을 재계산한다. 특정 작품이나 마디의 정답을 규칙에 넣지 않는다.

이는 기존 경과/보조/선행/계류 후보 규칙의 비교 계약 정비이며, 새 교재 단원 독해나 화성 정확도 개선의 확정이 아니다. 원주석, Core, 기존 실험 필드와 운영5173은 변경하지 않는다.

## 일반 규칙

1. 공통 관찰 범위 안에 온전히 들어오는 sounding event와 동일 성부 연결 가정을 사용한다. 범위 밖 끝음이나 생략음을 만들어 내지 않는다.
2. 후보 화음과 독립적으로 연속 세 음의 경과·보조 음형, 재타격/지속 선행음, 지속 후 하행 계류 형태를 수집한다.
3. 같은 음형에 화음 구성음/비구성음 조건을 적용한다. 유지 가정은 하나의 화음, 분할 가정은 양쪽 화음의 해당 시간 조건을 검사한다.
4. 이전 local 조건부 설명은 새 계산에 그대로 가산하지 않는다. 실제 membership에서 출발해 공통 규칙으로 다시 설명한다. 기존 계산은 별도로 보존한다.
5. 계류 형태는 준비·불협화·해결·박절 등의 필수 확인이 남아 있으므로 보류한다. 구성음이 아닌 음을 곧바로 확정 비화성음으로 간주하지 않는다.
6. 양쪽의 구성음 철자 집합이 같고 후보별 보류 사유가 없다면, 경계만 삽입해도 음표별 분류·시간 셀·총 음가가 같아야 한다. 이는 로마자 기능이 같다는 주장과는 다르다.
7. 실제 membership이 바뀌면 두 해석이 다르게 설명하는 것이 정상일 수 있다. 설명량만으로 승자, 확률, 최종 화성 경계를 정하지 않는다.

- `src/musicanote_harness/harmony_shared_context_trial.py`: 기존 고정 표본 replay와 대표 동일 화음 조합 검사.

207개는 후보 화음에 맞지 않는 형태도 남기는 새 catalog의 경계별 개수다. 이전135개 후보 필터 적용 패턴이나21개 계류 보류와 직접 증가율을 비교하지 않는다. 새 계류 형태24개도 실제 계류 정답 수가 아니다.

기존 JSON에서 이번 추가 필드만 제거했을 때 입력과 동일함을 검사했고 원자료/계획 hash를 보존했다. 이전 단계 counterfactual 파일은 복사 보존이며 이번에 모두 재실행한 것은 아니다.

신규14개 및 전체 **1,607개 Python 테스트 통과**. `git diff --check` 오류 없음(기존 파일의 CRLF 안내만 있음). 경과음 중간/내부 분할, 한쪽에만 위치한 음형, 보조음, 무연결, 실제 구성음 변경, 계류 보류, 지속 선행음, 이전 설명 누수 방지, 후보 보류, 외부 문맥 제한, 잘못된 성부 연결, 원본 보존, 제목 독립성을 검사한다.
