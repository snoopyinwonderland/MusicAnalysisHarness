# 화성 연구 엔진 v1 평가 마감

## 결정

사용자와 합의한 모델 고정 → 시험 A → 연결 판단을 기준으로, **새 연구 엔진의 편곡 연결은 보류하고 이번 v1 평가 작업을 마감**한다. 단계105 뒤에 예고했던 타이머 on/off 악보 비교는 실행하지 않는다. 추가 계수 조정·동일 전곡 재시도·runtime 진단을 자동으로 이어가지 않는다.

이것은 분석기가 완성됐다는 뜻도, 전체 작곡·편곡 프로젝트를 포기한다는 뜻도 아니다. 원악보 IR·출처·이론 규칙 계약·코드·개발/실패 기록은 재사용 자산으로 남긴다. 새 연구 엔진과 기존 화면용 화성 엔진을 구별한다.

## 판단 근거

- 고정 시험 A: 연구 엔진은 기존64셀 관문 때문에 전곡0/234, 기준선은231/234 완료. 이는 국소 화음 정확도0%가 아니라 전곡 처리 계약의 실패다.
- 후속 고정6곡 최신 정정 결과: 새 엔진2/6, control3/6, 봉인 기준선6/6 완료. 원결과를 덮어쓰지 않고 source 길이 validator 정정만 별도로 수행했다.
- 공통 완료2곡의 근음+3화음 종류 시간 일치: 엔진77.63%, 기준선79.61%. 작은 개발 표본이며 기준선 대비 확실한 우위가 확인되지 않았다.
- native 종료와 process 검사 실패가 남았다. stdlib4 비교 정상 종료는 전곡 안정성이나 음악적 성능 개선의 증거가 아니다.

따라서 사전 연결 관문은 FAIL이다. generation-ready 계약·Claude 외부 화성 연결을 승인하지 않는다. 학습 자료의 로컬 연구 이용 제한도 유지한다. 검사/해시 통과 수를 전체 완성률이나 음악 정확도로 사용하지 않는다.

## 보존과 이후 작업 경계

원source·IR·예측·모델·실험 출력은 로컬에 보존한다. 공개 저장소에는 기존 정책에 따라 코드·계약·개발 기록을 포함하고 원악보/코퍼스/학습 가중치/교재 상세 문서는 제외한다. GitHub만 clone하여 과거 실험 전체를 재현할 수 있다고 주장하지 않는다.

지금 진행하는 작업은 검색·구조 분석·뷰어를 MusicAnalysisHarness 한 저장소로 정리하는 **저장소 통합**이다. 새 화성 연구 실험을 추가하지 않는다. 이후 화성 개발을 재개하려면 목표·평가 자료·시간 상한·마감 기준을 별도로 정한다.
