# 지속음 내부의 화음 경계 검사 누락과 후보 과잉 위험

기록 ID: HARM-DEV-20260930-02. 연구용 경계 가설 추가·실제 악보 후보 검사. 최종 화성/NCT 판정, 정확도 개선 확인, 운영 승격이 아니다.

## 발견한 원인

[직전 실험](2026-09-30-cross-boundary-figures.md)은 계류음과 지속 선행음 규칙을 만들었지만 실제 고정 범위의 양성 후보가 0이었다. 경계는 해당 기보 성부의 연속 attack 시점에만 놓였다. 실제184표본을 조사하니 이 기존 경계에는 **문맥 안에 온전히 들어온 해당 성부의 지속음이 경계를 가로지르는 경우가0**이었다. 구현된 지속형 규칙에 맞는 관찰 기회가 없었던 것이다.

이는 모든 악보에서 성부 attack과 다른 음의 지속이 공존하지 않는다는 뜻이 아니다. 이번 고정 표본의 관찰 결과다. 이를 계류음 자체의 부재나 규칙의 음악적 타당성으로 해석하면 안 된다.

## 일반 규칙과 변경 범위

1. 기존 ready 표본의 시간 범위·전체 sounding events·기보 성부·모든 성부 연결 가정을 그대로 유지한다.
2. **어느 part이든 실제 새 음이 시작하는 시각** 중, 관찰 성부의 한 sound가 그 시각 전부터 후까지 지속하는 시각을 수집한다.
3. 그 sound의 시작과 끝은 기존 관찰 범위 안에 모두 있어야 한다. 문맥 밖 준비를 임의로 보충하지 않는다.
4. 기존에 검사한 경계인지 구별하고, 새 경계만 별도 결과로 계산한다. 동일시각의 여러 attack은 하나의 경계로 기록하되 근거 event IDs는 모두 보존한다.
5. 원주석·음높이 형태·원하는 화음·성공 여부로 경계를 고르지 않는다. 세 악장의 새 경계 계획 전체를 **새 후보 생성 전에** 파일로 고정한다.
6. 새 경계에도 기존 공통 카탈로그, 양쪽 구간, 같은 성부 연결, 비화성음 규칙을 적용한다. 임의 음높이·타이·기간 변경이나 후보 점수/최종 승자는 없다.

화성 변화가 다른 성부의 attack에서 반드시 발생한다는 가정은 아니다. release-only 변화, 새 attack 없이 생기는 변화, 더 긴 준비 문맥 등은 여전히 검사 범위 밖이다. 이번 범위는 기존 연구용 train 표본이므로 독립 평가가 아니다.

## 반례와 미확인 조건

모든135패턴에 대해 대표 호환 조합(첫 앞후보·뒤후보·supporting assignment)을 검사했다. 모든 후보 조합의 곱을 열거한 것은 아니다.

- 앞 또는 뒤의 해당 화음 조건을 반사실적으로 `abstention`으로 바꾸면 해당 후보색인의 설명이 사라진다. 원데이터는 복사본에서만 변경한다.
- 무연결 assignment에서는 경과/보조/준비된 계류 형태의 연결 근거가 사라진다.
- 하나의 sound가 경계까지 지속하는 선행음 후보는 무연결이어도 지속 사실이 남으므로 유지된다.
- 모든 비교에서 전체 음가·구성음·철자 미정 음가는 그대로이고, 비구성음의 지정 시간에만 조건부 설명을 더한다.

이것은 소프트웨어 조건과 보류의 작동 검사다. 사람이 확인한 음악적 양성/음성 라벨 평가가 아니다. 종전18개 규칙 테스트의 재타격≠지속, 상행≠하행 계류, 쉼·옥타브·이명동음 반례도 그대로 통과한다.

### 후보 과잉 위험을 보여 주는 실제 사례

K281 III `reviewm_555ff701230fc0b8ee66`, sample16:

- 관찰 범위:2마디+3quarter ~3마디+3quarter. 새 가정 경계:3마디+1/2quarter(global21/2).
- B♭4 `sound_0b9d0a329fff`/`note_4d67992530b4`는 `[10,12)` 동안 실제 지속한다. 이어 A4 `sound_82e6cfa6216c`/`note_24b72caac4b0`가 `[12,13)`에 나온다. tie chain 없이 하나의 기보음이 다른 성부의 attack을 넘는 경우도 포함한다.
- 기본 화면은 사후 검사 예시로 E♭major→Dmajor를 선택한다. B♭는 앞 후보 구성음/뒤 후보 비구성음, A는 뒤 후보 구성음이라 하행 계류 **형태 후보**가 성립한다.
- 그러나 앞 후보에는 G, 뒤 후보에는 F♯의 구간 내 근거가 없다. 경계 순간 실제 sounding notes는 E♭4·B♭4·G5다. 따라서 기본 Dmajor 가설이나 계류 판정을 음악적 정답으로 채택하지 않는다. 경계 뒤의 더 긴 구간으로 화음을 가정한 현재 방식의 한계를 드러낸다.
- UI에 각 후보의 `missing_spellings`를 노출했다. 모든 구성음이 있어야만 화음이 되는 것은 아니지만, 빠진 음과 상충 근거를 숨긴 채 조건부 NCT를 확정해서도 안 된다.
- 이 조합의 기존 분할은 구성음5, 조건부NCT0, 미설명7quarter다. 문맥 추가 후 각각5, 3/2, 11/2quarter다. 합12quarter이며 새 설명3/2은 `[21/2,12)`에만 적용된다. 설명량 증가가 올바른 화성의 증거는 아니다.

[전체 악보에서 해당 예시](http://127.0.0.1:8819/real-cases/reviewm_555ff701230fc0b8ee66/whole-score.html?sample=16), [전체 목록](http://127.0.0.1:8819/index.html). 로컬 서버 실행 중에만 열린다. root/quality는 기능 로마자가 아니므로 일반 글꼴로 표시한다.

## 구현·검증·재현

- `harmony_held_boundary_audit.py`: label-blind 경계 계획, 보류 조건 반사실 복사.

- `harmony_held_boundary_trial.py`: 사전계획·hash원장·실제 표본·반사실 검증·전체 악보 페이지. 이전 결과를 덮어쓰지 않는다.

- `tests/test_harmony_held_boundary_audit.py`: 신규10개. 다른 성부 attack/중복/기존 경계/재타격·release/문맥밖 sound/보류/pitch비의존/이전계약/잘못된 경계/양쪽후보 보류 검사.

## 결정과 다음 단계

**다른 성부의 attack을 놓치던 검사 누락은 보완했다. 음악적 계류/선행음 양성 검증 공백을 해소했다고 선언하지 않는다.** 오히려 후보 조합만으로 여러 설명이 성립하는 과잉 가능성을 실제 자료로 확인했다.

다음은 경계 직전/직후·해결 순간의 실제 베이스와 수직 음정, 후보 구성음의 시간별 지지/결손, 박절 위치를 별도 evidence로 연결한다. 이후 원주석 및 이론과 비교해 명확한 계류음과 보류 사례를 고정한다. 전후 화성 기능·조성을 확인하지 않고 설명량만으로 화음이나 프레이즈를 변경하지 않는다. 현재 사용자 판단을 요구할 확정 제안은 없다.
