## 고정 점수의 문제와 새 계약 방향

현재 음표 노출과 시간 특징은 전곡 시간 또는 note-time으로 나뉘고 run-count/일부 전이 비용은 횟수 단위다. 작품이 길어지면 국소 부적합의 비용은 희석되지만 화음을 바꾸는 비용은 같은 크기로 남는다. 별개로 확장화음의 일부 구성음 역할 특징은 지원하지 않아 null이며, 현재 정책상 비용에 기여하지 않는다. null은 음악적으로 문제가 없다는 의미가 아니다.

다음 버전의 목표는 아래 불변성이다. 아직 새 숫자를 학습하거나 운영 점수를 만든 상태가 아니다.

- **길이 일관성:** 같은 독립 구간을 반복했을 때 동일한 화음 진행을 반복한 경로의 비용과 경쟁 순위가 불필요하게 바뀌지 않아야 한다. 경계 문맥이 실제 달라졌을 때의 변화는 별도다.
- **같은 단위:** source 노출을 국소 기준박/동시음 수의 측도로 적분하는 비용과 화음 변경·해결 비용을 공통 단위로 정의한다. 전체길이로 보고값을 나눈다면 모든 항을 경로 합산 후 동일하게 나눈다. 현 모델에서 일부 항만 나누는 정책과 동일하다고 주장하지 않는다. 기존26계수의 의미가 달라질 수 있어 새 모델 버전과 재평가가 필요하다.
- **후보 범위:** page는 계산 편의상 경계일 뿐이다. 후보가 처음 제시된 page와 이후 유지되는 구간을 분리하며, 후속 실제 구성음·명시성부 해결·근음/베이스 지지·새 강박 진행을 사용해 지속 가설과 변경 가설을 함께 비교한다. ‘한 번 들은 구성음’만으로 끝까지 유지하지 않는다.
- **모델 적용 범위:** 3/7화음의 역할 특징을 평가할 수 없는 확장화음을 같은 계수로 완전히 검증했다고 읽지 않는다. 확장화음은 별도 지원/보류 상태를 갖고 유효 역할 근거가 없으면 생성용 확정 화음으로 승격하지 않는다. 무조건 삭제하거나 null을 가상 관찰로 채우는 것도 금지한다.
- **진행 대 구간:** 실제 root+spelled members 변화와 bass/전위 변화, 무음 gap을 별도 기록한다. 베이스가 달라진 제출span을 새로운 화음 선택 성공으로 세지 않는다.
- **탐색 책임:** 후보 포함률, 같은 그래프에서의 최적/근사 선택 손실, 음악 정확도를 별도로 측정한다. 직접 비용 재검산은 음악 정답 보증이 아니다.
