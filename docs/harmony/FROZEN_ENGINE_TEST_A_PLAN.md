## 2. 시험 A와 단순 기준선

- 자료: `K:/Music Composition/docs/handoff/harmony_eval/harmony_benchmark_gold.json` 234곡. 추론 입력은 Piano Solo 원파일만이다. gold/리드시트/정답 조성·화음은 예측기에서 읽지 않는다. 원파일의 harmony 기호는 메모리 파싱 시 제거한다.
- 메타데이터만 전달하는 입력 manifest와 채점용 gold를 분리한다. 반주 학습 holdout과 화성 개발 독립성은 다르다. 기존 사례 문서의 제목/파일명·기록된 출처 해시를 대조하고 이력 불완전성을 명시한다. 독립성을 과장하지 않는다.
- 전체 악보의 기보 시간, quarter Fraction, 못갖춘마디 실제 길이, 붙임줄 sounding event, 반복 미전개. 모든 성부와 베이스를 입력한다. gold 길이로 원악보를 자르거나 늘리지 않는다.
- 곡당 60초(프로세스 시작·파싱·추론 포함), 동시4프로세스, 재시도0. 실패곡의 부분 예측은 공식 제출에서 제외하며 전체234곡 분모에 유지한다. 완료곡 수와 유효 화음 시간 coverage를 별도로 보고한다.
- 기준선: 박자 분모 단위의 beat 창에서 실제 울린 전체 성부의 시간 가중 pitch-class를 고정 3·7화음 템플릿에 맞춘다. 모형 학습/리드시트 열람/정답 기반 조정 없음. 기준선도 같은 입력·시간 제한·unknown 계약을 사용한다.
- 제출은 Claude README 형식 `start,end,root_pc,pcs,bass_pc`. pcs는 선택한 화음의 구성음이며 관찰된 비화성음을 합친 집합이 아니다. unknown bass는 null로 유지한다.
- 채점 보완: 정렬·양의 길이·중첩 없음·pc 범위 검증, 경계 일대일 ±1/2quarter 매칭, 누락곡 경계 FN 포함, null bass 근음 대입 금지. 원 채점기의 수치도 참고용으로 보존하되 연결 결정에 사용하지 않는다.
- 두 제출을 모두 봉인한 뒤 gold를 채점에 읽는다. 전체234곡과 기록상 노출 미발견 subset을 별도 보고한다. root/triad/pcs/bass/경계 P·R·F1, 완주율/화음시간coverage, 중앙·p95시간, 실패 원인을 저장한다.
