## 검사와 이번 비교의 종점

1. active sweep의 half-open·동률 원순서, 모든 합성span/철자 후보의 기존 대 새 비용, 변박/복합박/unknown, 조건부음/준비 지연, 실제 양수pair와 설명, 셀마다 frontier/버린상태/연산 수, 전체catalog/source/path 동등성, 부분경로 미제출을 검사한다. 기존37회귀도 유지한다.
2. 단계99의 같은6곡을 그대로 사용한다. 이미 쓰인 개발자료이며 독립Test가 아니다. **원99 control과 최적화 adapter를 각 한 번**, 곡당60초·동시4로 실행한다. 이 단계는 새 구현의 통제 비교이지 시간초과 곡 재시도/계수 sweep이 아니다.
3. 원99에서 이미 봉인된 박 템플릿 기준선은 정확도 비교용으로 재사용한다. 이번 기준선 시간을 새로 측정했다고 말하지 않는다. control/adapter의 새 예측과 원기준선 파일 해시를 고정한 뒤 같은6곡 gold를 읽는다.
