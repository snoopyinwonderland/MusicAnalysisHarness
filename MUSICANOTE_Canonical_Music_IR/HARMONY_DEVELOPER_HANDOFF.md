# 화성 개발 인수인계 — 전달 시 참고용

이 문서는 일상적인 개발 기록의 정본이 아니다. 화성 분석은 별도 [개발 문서](../docs/harmony/README.md)와 [개발 로그](../docs/harmony/DEVELOPMENT_LOG.md)에서 관리한다.

기존에 여기에 누적된 개발 내용은 삭제하지 않고 [문서 분리 이전 이력](../docs/harmony/archive/DEVELOPMENT_HISTORY_THROUGH_2026-09-29.md)으로 보존했다. 이전 링크의 진입점으로 이 파일을 유지한다.

## 실제 인수인계가 필요할 때

- 전달할 코드 버전/commit 및 미커밋 변경을 명시한다.
- 개발 문서의 현재 상태와 테스트·실험 재현 명령을 연결한다.
- 운영에 적용된 버전과 연구용 실험 버전을 구별한다.
- 필요한 원자료·manifest·IR·출력의 경로/hash 및 사용 권한을 확인한다. `output/`과 외부 자료는 Git push만으로 전달되지 않는다.
- 새 환경에서 재현한 결과와 남은 제약을 기록한다.

인수인계 요청이 있을 때만 이 전달용 요약을 갱신한다. 새 설계·구현·실험·사례·실패 기록은 개발 로그에 남긴다.
