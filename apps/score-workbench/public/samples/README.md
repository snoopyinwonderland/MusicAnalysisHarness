# Instrument samples

Piano, violin, viola and cello notes from the FluidR3_GM SoundFont by Frank Wen, rendered per note by
gleitz/midi-js-soundfonts (https://github.com/gleitz/midi-js-soundfonts).

Licence: Creative Commons Attribution 3.0 (FluidR3_GM).  Keep this attribution when redistributing.

One sample every three semitones (`<instrument>/<midi>.mp3`, listed in `manifest.json`).
Inside each bank's covered range the nearest sample is at most one semitone away.
The player limits out-of-range pitch shifting and falls back to its basic sound when necessary.
Total size about 1.8 MB.
