원본 파일 회수는 지정 sourceId가 top100에 등장함을 뜻한다. 같은 제목은 단순 정규화 제목 후보로, 동일 작품 검증값이 아니다. 원래 구간은 동일 workId/성부에서 보존 대상 음의 onset/pitch가 80% 이상 대응하는 보조 지표다.

선별: 원본 XML의 약박, 짧은 음가, 순차진행과 주변 지지 근거. 화성·사람의 분석이 없는 잠정 장식음 후보이며 확정 기둥 분석이 아니다. 삭제 시 음가도 제거해 뒤의 박자 위치가 이동한다.

원형이 검색된 10개 중 두 음 삭제도 검색된 것은 8개. 목표 수량을 맞추려고 선별 조건을 완화하지 않았다. 서로 다른 원본 파일 5개의 편의 표본이며 전체 성능으로 일반화할 수 없다.

현재 엔진만 실행했으며 두 음 삭제 전용 검색 로직은 개발하지 않았다. Query/삭제음/원본 XML 좌표·문맥은 suite.json, 전체 결과는 evaluation/runs/double-ornament-trial-v3, 요약·상위3결과는 results.json.
