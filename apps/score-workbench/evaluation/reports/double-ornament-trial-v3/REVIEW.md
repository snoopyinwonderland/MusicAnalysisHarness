# 장식음 두 개 삭제 추가 실험 — 최종 해석

| 조건 | 완료 | 원본 Top5 | 대표 정렬의 원래 구간 대응 |
|---|---:|---:|---:|
| 원형 | 10/10 | 10/10 | 5/10 |
| 한 음 삭제 | 10/10 | 10/10 | 6/10 |
| 두 음 삭제 | 10/10 | 8/10 | 4/10 |

오류·시간초과·재시도는 0건. 각 Query는 실제 검색 엔진에 실행했다. 두 음 삭제 실패 2건은 동일 Query의 서로 다른 반복 위치다. 고유 Query 기준은 7/8 성공(87.5%). 성공한 원본은 모두 1위 또는 3위다. 전체 10개는 5곡·8개 고유 음표열의 편의 표본으로 일반적인 성공률 추정에 부족하다. 모두 4/4, 떨어진 두 장식음 후보 삭제다.

## 미회수 원인

ORN06(가장 무도회 20–24마디)과 ORN09(48–52마디)는 원형·한 음 삭제 1위, 두 음 삭제 top100 미회수다. 시간초과가 아니다. 원본 work는 inHits/inCandidates에 모두 들어왔지만 기록된 평가 창은 key의 시작 0, windowStart 0이다. 실제 원형 시작 index는 52/140이다. 해당 창은 local 약 59.91, interval 약 73.82, rhythm 약 36.16으로 admission-floor에서 탈락했다.

즉 곡 전체가 후보에서 누락된 것이라기보다 적절한 위치가 평가 창으로 전달되지 않은 정황이다. 이 trace만으로 모든 내부 후보 생성 원인을 확정하지는 않는다. 총점·통과 기준 완화나 특정 작품 보정은 하지 않았다.

향후 보완한다면 삭제 양옆의 연결 음정을 고려한 위치 후보를 제한적으로 보충하고, 올바른 원본 창을 평가했을 때의 정렬과 비교해야 한다. 별도 음정 오류·무관한 선율을 통과시키지 않는 음성 대조군과 속도 회귀 검증이 선행돼야 한다.

## 곡 회수와 위치 회수를 구별

- 대표 정렬의 원래 구간 지표는 동일 성부에서 남은 음의 onset/pitch가 80% 이상 대응하는지다. 같은 선율의 다른 반복을 대표로 선택하면 낮아지므로 곧바로 잘못된 검색으로 해석하면 안 된다.
- ORN01(실비오는 소리에)은 두 음 삭제 시 26–30마디가 대표이고 원래 47마디는 반복 목록에 있다. 대표 정렬은 남은 14음 중 13음만 연결하고 마지막 Query 음을 deletion 처리했다.
- ORN03(잃어버린 우산)은 원래 구간을 찾았지만 14음 중 13음만 정렬됐다. 음표 표시 완전성과 곡 검색 성공은 별개다.
- ORN04/ORN07/ORN08은 다른 반복 구간으로 14음의 음높이·음가가 대응하며 일정한 onset 이동이다. 원래 시작 마디도 반복 목록에 있다.
- ORN10(CARO MIO BEN)은 onset 이동 0으로 남은 14음이 그대로 대응한다. 원본 색인 마디 15–18과 반환 표기 14–17의 차이 때문에 단순 마디 숫자 기반 반복 목록 검사는 false다. 음표 좌표상 미회수가 아니다. 마디 좌표/표시 번호 정규화는 별도 점검할 사항이다.
- 두 음 삭제의 반복 목록에서 시작 마디 번호가 일치한 것은 7/10이다. 위 번호 차이 때문에 이 지표를 절대 정답으로 사용하지 않는다.

## 판단

사전 기준인 원본 대비 20%p 하락에 도달했다(10개 구간 기준 100%→80%). 다만 같은 실패 Query가 2회이므로 독립 실패 2개는 아니다. 현재 동작을 제거하거나 일반 검색을 더 느슨하게 하지 않고, 두 음 삭제 전용 확장은 보류한다. 사례는 회귀 자산으로 유지하고 위 후보 위치 병목을 후속 개선 대상으로 남긴다.

원형·Query·삭제 이유·XML 문맥은 suite.json, 전체 결과는 evaluation/runs/double-ornament-trial-v3, 요약은 results.json, 구간 감사는 audit.json, 악보/소리는 index.html에 있다. 브라우저 시각/청각 검수를 모두 완료했다는 의미는 아니며 30개 악보 생성과 음표 ID·스크립트 검증을 수행했다.
