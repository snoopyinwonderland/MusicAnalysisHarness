# S-STRUCT-008 — ALWAYS WITH ME

사용자: “프레이즈2는 프레이즈1 앞부분의 반복인데 분리되었습니다. 2와3이 합쳐져야 합니다.”

현행 Phrase1 [0,30), Phrase2 [30,35), Phrase3 [35,60). 제안은 [30,60)이며 음표 ID와 전체 XML/현행 snapshot은 ../case-assets/S-STRUCT-008/에 보존한다.

첫5음은 D4 E4 F#4 D4 A4 → D5 E5 F#5 D5 A5로 옥타브 대응한다. 원형 A4는1.5 quarter, 재등장 A5는1 quarter+쉼0.5 quarter이다. 두 경우 모두 다음 F#까지 onset 간격은1.5 quarter로 같다. 그런데 현재 국소 경계는 재등장의 쉼에0.75를 부여하여 분리한다. 대응 전체의 내부 호흡인지 판단하지 못한 사례다.

기존 비교기로 전체30음 결합안을 원형30음과 대조: 유사도92/100, coverage93%, 양 끝음 정렬. 이 수치는 보정 확률이 아니고 끝음 대응도 종지 동일성을 뜻하지 않는다.

일반 규칙 검증 후보: 반복 대응에서 음가 일부가 쉼으로 대체되어도 다음 attack까지의 시간과 선율 진행이 유지되면 내부 호흡 대안을 생성한다. 단, 쉼을 삭제하거나 원본 음가를 합치지 않고 실제 호흡기호/강한 종결 근거를 보호한다. 전체 대응·외곽 경계·다른 반복 문맥도 검증해야 하며 특정 작품 예외를 만들지 않는다. 현재는 사례 보존/진단이며 production 경계는 변경하지 않는다.
