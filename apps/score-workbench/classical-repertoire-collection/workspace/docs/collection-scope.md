# Collection scope

## Goal

Build an expanding authority-backed registry of classical repertoire. The 2026-09-08
v4 list is a baseline, not a cap. The 154-work queue is an XML acquisition pilot and
does not limit metadata or repertoire-list collection.

"All music" in this project means the widest feasible coverage of classical repertoire:
works, movements, excerpts, arrangements, versions and relevant catalogues across eras,
regions and composer communities. It does not mean that every listed work has an
immediately downloadable MusicXML file.

## Separate coverage tracks

1. **Authority list coverage** — collect and reconcile composer and work metadata from
   documented catalogues. This remains active until each registered source has been
   harvested or explicitly recorded as inaccessible.
2. **Relationship coverage** — model whole-work, movement, excerpt, arrangement,
   revision and edition relationships instead of flattening them into duplicate titles.
3. **Rights coverage** — record source, edition and file rights separately from the
   underlying composition's historical status.
4. **Score-file coverage** — acquire only lawfully available files with provenance and
   validation. XML availability never controls whether a work belongs in the catalogue.

## Inclusion policy

- Retain every baseline work while authority verification is pending.
- Add works from composer-specific catalogues before treating broad aggregators as a
  complete catalogue.
- Continue the existing expansion of women, non-European traditions, Black composers,
  Korean and other East Asian composers, Latin American repertoire, education repertoire
  and living composers.
- Preserve uncertain attribution, incomplete fragments and lost works as records with
  an explicit status when a recognised catalogue includes them.
- Record the source and retrieval date for every added or changed assertion.

## Operational priority

1. Resolve the 23 S-grade composer catalogue mappings.
2. Add and verify the 30 supplementary-composer candidates.
3. Process all A-grade `Complete catalogue 우선` composers.
4. Add new authoritative source registries by era, region and repertoire type.
5. Keep XML acquisition as a separate, availability-driven stream; begin with the
   154-work pilot but do not use it to filter the catalogue.

## Completion language

Do not describe the registry as "complete" by work count alone. Report coverage by
registered authority source, composer, work relationship, rights evidence and file
availability. The catalogue is expected to grow as new sources and works are found.
