# When We Disco / 철없던 사랑 직접 비교

## 결론

두 곡의 주요 선율에는 시스템으로 확인되는 강한 유사 구간이 있다. 가장 명료한 대응은 When We Disco 4–5마디와 철없던 사랑 23–24마디다. 다만 같은 음 반복 비중이 높은 음형이므로 일반 코퍼스 검색에서는 오탐 방지 하한에 걸려 최종 결과로 나오지 않는다.

이 평가는 저작권 침해 판정이 아니다. 명시적으로 선택한 두 작품의 음표·리듬·박자 구조를 비교한 기술적 유사성 근거다.

## 검색 동작과 수정

scopeWorkIds는 원래 이미 q-gram으로 회수된 후보를 좁히는 필터로만 쓰였다. 따라서 사용자가 두 작품을 명시해도 대상 작품이 q-gram 후보에 없으면 직접 비교되지 않았다. 지정된 작품은 full-scan 후보로 반드시 평가하도록 고쳤다.

수정 후 대상 작품은 실제 평가되지만 대표 Query는 low-information-floors에서 제외된다. 반복음 Query의 일반 검색 하한을 느슨하게 하면 오탐이 크게 늘 수 있으므로 변경하지 않았다. 향후 작품 대 작품 비교 화면에서는 이 경우 결과를 숨기지 않고 반복음 중심·낮은 식별력 경고와 점수별 근거를 함께 보여주는 것이 적절하다.

## 두 작품이 함께 회수되는 Query 재검증

두 곡이 의미 있게 공유하는 가장 짧은 골격은 `G♭5(0.5)-G♭5(0.5)-G♭5(0.5)-G♭5(0.5)-F5(0.5)-E♭5(0.5)-F5(0.5)`다. 음정열은 `0, 0, 0, -1, -2, +2`이며 철없던 사랑에서는 한 음 아래의 `F5-F5-F5-F5-E5-D5-E5`로 나타난다.

- 두 작품을 검색 범위로 지정하면 When We Disco 1위 100점, 철없던 사랑 2위 100점으로 함께 회수된다.
- Exact Interval을 켜도 두 작품 한정 결과는 동일하다.
- 전체 코퍼스 검색에서는 두 작품 모두 Top200에 들지 않는다. 7음 반복음 중심 seed가 너무 흔해 짧은 Query 후보 상한에서 밀리기 때문이다.
- 동일 음정열 8음 이상은 리듬까지 같은 연속 구간이 없었다. 리듬을 무시하면 8–11음 공통열도 발견되지만 긴 무음 구간을 건너뛴 공격음 나열이어서 정상적인 단일 Query 근거로 사용하지 않는다.

따라서 이 사례는 일반 전역 검색용 Query보다 `Search Within Results` 또는 두 작품 직접 비교의 근거 Query로 사용하는 것이 타당하다. 전역 검색에서 억지로 함께 나오게 만들기 위해 반복음 후보 상한을 완화하지 않는다.
