# 강도 2 멜로디 변형 검색 100개

## 최종 결과

본 실행 변형 100개 + 원형 대조 20개 완료. 최초 60초 안에 변형 95개/대조 18개 완료, 나머지 변형 5개/대조 2개는 별도 180초 재시도에서 모두 완료했다. 최초 시간 초과를 덮어쓰지 않았다.

| 변형 | 원본 source 회수 / 20 |
|---|---:|
| 두 음 2~3반음 변경 | 3 |
| 두 음 옥타브 이동 | 1 |
| 두 곳 리듬 재분배 | 20 |
| 두 도약 축소 | 2 |
| 두 곳 쉼 삽입(총길이 유지) | 20 |

최종 원형 대조 20/20 회수. 변형은 46/100 회수(재시도로 증가 없음), 1위 26개, 상위 5위 44개, 원본 성부/좌표 구간 proxy 40개다. 정확한 원본 파일 대신 다른 편성이 검색되는 사례가 있으므로 이는 작품 전체 recall과 동일하지 않다. 최초 완료 변형의 중앙 시간 17.91초, p95 52.70초이며 시간 초과 5개는 별도다.

검색 결과가 있는 94 Query의 대표 결과를 실제 XML/Verovio로 검사했다. 94개 모두 로드 및 강조 ID 확인, 미해결 target 0. 나머지 6개는 결과 자체가 없어서 렌더링하지 않았다. 일부 excerpt에 열린 tie 경고가 출력됐으므로 ID 검사 통과를 판면/타이/청취까지 완벽하다는 주장으로 쓰지 않는다.

### 관찰과 개선 방향

1. 음높이 두 곳 변경은 인접 interval 여러 개를 동시에 바꾼다. 후보 생성 단계와 최종 admission 단계의 누락을 분리 진단해야 한다. 이번 테스트 중에는 엔진이나 기준을 바꾸지 않았다.
2. 국소 옥타브 두 곳 이동은 전체 전조와 다르며, 현재 강한 취약점이다. 옥타브를 무조건 무시하지 말고 문맥/변형 수 제한과 음성 대조군을 함께 검증해야 한다.
3. 리듬과 쉼은 이번 강도에서 안정적이지만 총길이 보존 변형이다. 임의 시간 늘림이나 복합 음높이+리듬 변형 전체로 일반화하지 않는다.
4. Q-H100-024(He Will Hold Me Fast)의 source 11위, Q-H100-099(A Whole New World)의 source 20위는 별도 검토 사례다. 상위 후보 중 실제 local/interval 수치가 더 강한 것도 있으므로 순위 오류로 즉시 확정하지 않는다. 비교 정보는 competitor-review.json에 저장했다.
5. 20개 기반 표본은 KYSing 10개/MusicXML 10개이고 PDMX 원형은 없다. 4/4 외에 3/2·2/2·6/8·3/4를 포함한다. 과거 자료에서 두 도약 조건을 만족하는 선율을 선택한 편의 표본이므로 전체 데이터베이스 성능으로 환산하지 않는다.

## 요청 및 고정 설계

기존 변형보다 한 단계 강한 변형 100개를 실제 전체 DB에서 검색한다. 기존 motif 자료에서 서로 다른 정규화 제목 20개를 선택해 각 5개 변형을 만든다. 선택은 검색 결과를 보기 전에 결정한다. 원형 대조 20개는 별도 통계로 실행한다. 범용 recall 개선 여부를 확정하는 무작위 표본이 아니라 paired stress test다.

- two-pitches: 내부 두 음을 +2 / -3반음 변경.
- two-octaves: 내부 두 음을 +12 / -12반음 이동(MIDI 범위에 따라 방향 변경).
- two-rhythm-pairs: 두 쌍에서 뒤 음의 절반을 앞 음으로 이동. 총길이 보존.
- two-leaps: 서로 인접하지 않은 도약 두 개를 최대 5반음 축소.
- two-rest-splits: 내부 두 음의 후반 절반을 쉼으로 변경. 총길이 보존.

10음 원본에 두 도약이 있어야 하므로 순차 진행 위주 선율에는 선택 편향이 있다. 이전 시험의 원형 복구는 현재 DB의 음높이/onset/원본 좌표 일치를 확인해 수행한다. 2박 초과 내부 쉼은 제외한다. 원본 events와 앞뒤 2마디를 보존한다.

## 실행과 재현

`node scripts/run-harder-100.mjs evaluation/runs/harder-100-2026-09-15`

중단 시 같은 명령 뒤 `--resume`. DB 크기/수정 시각 및 엔진 코드 지문이 다르면 재개하지 않는다. 각 결과를 즉시 저장한다. 단일 persistent worker, Query당 60초 제한, top 100, 기본 검색 알고리즘, contour sidecar 비활성. 실행 중 엔진 변경 없음. 기존 top 30 결과와 직접 성공률 차이를 비교하지 않는다.

요약: `node scripts/summarize-harder-100.mjs evaluation/runs/harder-100-2026-09-15`.

실행 결과 및 100개 Query 표는 위 디렉터리의 report.md, 상세 데이터는 suite.json·개별 JSON·summary.json·analysis-summary.json에 모은다. 원곡 source 회수/원본 구간 회수 proxy/실패/latency를 구분한다. API 좌표 유효성은 실제 악보 SVG/청취 검증을 대신하지 않는다. 검색 상위 경쟁곡의 음악적 정당성은 미검토로 남기며 원곡을 정답 순위로 강제하지 않는다.
