# Phrase v1.12 — 기준 박 대비 종결과 구간 완결성

사용자 후속 의견: FIND THE WAY의 v1.11 Phrase 8+9,15+16+17을 합치는 것이 좋다. 네 음은 Motif로 가능하나 Phrase 완결성이 부족할 수 있고, 매우 짧은 음과 짧은 쉼만으로 끝내지 말 것. 추가 지시: 짧은 음은 상대적이므로 기준 박을 볼 것.

기존 S-STRUCT-005 원본과 문맥을 재사용한다. 당시 번호의 index 대응은 8=[79,84),9=[84,92),15=[128,132),16=[132,136),17=[136,160). 규칙은 번호/제목/음높이를 참조하지 않는다.

v1.12는 고정16분음표 조건이 아니다. 단순2/3/4박자는 분모 단위, 6/9/12의8분 복합박자는 점4분 단위를 잠정 기준 박으로 삼는다. 비대칭/미상 박자는 이 보정을 보류한다. 연주자의 실제 박감이나 tempo는 추정하지 않는다.

종결음 <=1/4 기준박이고 주변4음 중앙값 이하, 뒤 gap <=1/2 기준박이면 독립 종결 근거가 약하다고 본다. 또는 현재 원래 후보 구간이4attack 이하/4기준박 미만이고 종결음 <=1/2 기준박 및 주변 중앙값2배 이하, gap<1기준박이면 하위 음형 후보로 낮춘다. 명시적 호흡 기호는 보존한다. 길게 쉰 뒤 재시작하는 예외도 유지한다. 이는 보정되지 않은 기본 경향이며 cadence의 부재를 판정한 것이 아니다.

기존 최소음수/반복 프레임 후처리 뒤 적용하여 이미 억제한 경계를 새로 되살리지 않는다. rawStrength/cue/기준박/상대음가/주변중앙값을 보존한다. Motif 분할은 별도이며 이 경계들을 삭제된 사실로 취급하지 않는다. v1.11의 가까운 지속 종결 검사도 기준박 배율로 환산했다.

결과:84/132/136이 억제되고79/92/160은 유지된다. 같은 규칙으로119/128도 약화되어 해당 앞 구간까지 추가 병합된다. 그러므로 요청한15–17만 정확히 선택 병합한 것은 아니며,30마디 이전과의 연결은 다음 시각 검토 대상이다. 자동 규칙의 일반적 영향과 사용자 선호를 구분한다.
